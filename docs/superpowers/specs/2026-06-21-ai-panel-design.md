# AI 面板设计文档

> 2026-06-21 | 状态：已批准

## 概述

在画布右侧添加 AI 对话面板。用户填一次 API Key 后即可使用，AI 面板提供探索关联、润色内容、检查关系等辅助功能。核心原则：**AI 只辅助，不替代用户创作**。

## 文件变更

```
src/
├── services/
│   └── ai.ts                    # [新增] API 调用封装（OpenAI 兼容格式）
├── components/
│   ├── AIPanel.tsx              # [新增] AI 对话面板
│   ├── AISettings.tsx           # [新增] API 配置表单（Key地址、API Key、模型名）
│   └── MindMap.tsx              # [修改] 加 AI 面板开关、反向链接面板改为左侧、加 AI 工具栏按钮
```

## API 调用（ai.ts）

- 调用格式：OpenAI Chat Completions 兼容
- 用户配置项：`apiUrl`、`apiKey`、`model`
- 配置存储在 localStorage `mindmap_ai_config`
- 请求方式：POST，body 包含 `model`、`messages`、`temperature`
- 错误处理：显示具体错误信息（401=Key 错误、网络=连接失败等）

### 快捷按钮

| 按钮 | 触发条件 | 发送给 AI 的内容 |
|------|---------|-----------------|
| 探索关联 | 选中 1 个节点 | 当前节点名+内容 + 所有其他节点名列表，要求列出可能相关的节点及原因 |
| 润色内容 | 选中 1 个节点 | 当前节点内容，要求修正错别字优化表达，不改原意 |
| 检查关系 | 选中 2 个已连线节点 | 两个节点的名+内容 + 连线内容，要求检查关系是否准确、有无遗漏 |
| 自由提问 | 始终可用 | 底部输入框 |

未选中的快捷按钮置灰，hover 时提示原因（如"请先选中一个节点"）。

### 情境感知的隐私

AI 看到的数据仅限用户明确触发快捷按钮时的节点/连线内容。自由提问模式下，AI 看不到画布数据，除非用户在对话中主动提及。

## 面板位置

- **AI 面板**：右侧，`fixed right-4 top-24`，宽 320px，高自适应最大 70vh
- **反向链接面板**：改为左侧 `fixed left-4 top-24`，宽 320px，最大 70vh
- 两个面板可同时打开，不互斥
- 工具栏加 AI 按钮（紫色渐变，`BrainCircuit` 图标），选中单节点时可见

## AI 对话交互

- 用户点击快捷按钮 → 自动构建 context prompt 发送
- AI 返回后，结果渲染在对话区
- 对话区支持 Markdown 渲染（用简单的 markdown-to-jsx 或手动正则替换）
- 输入框支持 Shift+Enter 换行，Enter 发送
- 对话历史保留在当前会话中，不持久化

## AIPanel 组件 Props

```ts
interface AIPanelProps {
  nodes: Node[];
  connections: Connection[];
  selectedNodes: Set<string>;
  getNodeName: (id: string) => string;
  onClose: () => void;
}
```

AI 面板通过回调从 MindMap 获取当前上下文，但不直接修改 nodes/connections。用户需要手工执行 AI 的建议（创建连线、修改内容等），AI 不自动修改数据。

## 技术要点

- AIPanel 内部维护 `messages` 状态数组 `{role, content}[]`
- 发送消息时，把 messages 转为 OpenAI 兼容格式请求
- 首次使用时若未配置 Key，自动弹出设置弹窗
- Key 加密存 localStorage（简单 base64，仅防明文字符串泄露，不是安全加密）
